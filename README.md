A one-sentence, one-star review of planet Earth written by an alien tourist
who still has to admit the food was excellent — an entry for the
[One Star, Five Stars for the Food](https://make.fun/c/u-po-pu-one-star-five-stars-for-the-food-f9166ee7)
bounty on make.fun.

## Entry

> One star: Earth towed my spaceship, the locals photograph dinner before eating it, yet the dumplings alone were worth the interstellar parking fine.

## How it works

`main.py` writes that sentence — exactly one sentence, 148 characters — to
`entry.txt` in the output directory (`$MAKEFUN_OUTPUT_DIR`, default
`/output`). No network, no secrets, no dependencies: just the sentence.

Run it:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
